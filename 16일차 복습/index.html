ul태그와 ol태그

주의사항

  1. ul태그나 ol 태그 없이 li 사용 -> 웹 표준에 적합하지 않음
  2. 가독성 때문에 사용하는 경우가 많다 -> 같은 카테고리에 2개 이상이면 li태그 적극 활용
  3. ul과 li에도 클래스 속성 필수 활용
  4. nav 태그에만 ul, li를 써야 하는 건 아니다

ul태그

ul과 li는 html 레이아웃 구현 시 적극 활용

ol태그

ol과 li는 html 블로그, 뉴스, 공지사항 등 순서가 중요한 구조에만 활용

  1. 라면 봉지를 뜯는다.
  2. 면과 스프를 분리한다.
  3. 냄비에 물을 넣는다.
  4. 냄비에 면과 스프를 넣는다.
